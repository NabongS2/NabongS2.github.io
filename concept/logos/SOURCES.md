# 로고 원본

글의 커버와 도식에 쓰는 제품 로고. 그림을 그리지 않고 공식 마크를 그대로 쓴다.

| 파일 | 출처 | 브랜드 색 |
| --- | --- | --- |
| `redis.svg` | simple-icons `icons/redis.svg` | `#FF4438` |
| `docker.svg` | simple-icons `icons/docker.svg` | `#1D63ED` |
| `spring.svg` | simple-icons `icons/spring.svg` | `#6DB33F` |

받아온 곳은 `https://cdn.jsdelivr.net/npm/simple-icons@latest/icons/<이름>.svg` 다.

두 파일 모두 `fill` 이 비어 있는 단색 패스 하나다. 쓸 때 `<svg>` 에
`fill="#FF4438"` 처럼 색을 지정한다. 다크 테마에서도 브랜드 색은 그대로 둔다.

## 쓸 때 지킬 것

도형과 비율은 고치지 않는다. 색은 브랜드 색이나 단색(검정·흰색)만 쓴다.
제품을 가리킬 때만 쓰고, 이 블로그가 해당 제품과 관계가 있다는 인상을 주는
자리에는 두지 않는다.

Redis 는 Redis Ltd., Docker 는 Docker, Inc., Spring 은 Broadcom Inc. 의 등록 상표다.
