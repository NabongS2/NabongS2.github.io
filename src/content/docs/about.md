풀스택 웹 개발자 **나봉**입니다.

AICC 콜봇을 도메인으로 하는 기술 연구소에서 웹어드민과 콜봇 시스템에 필요한 데이터 설계 및 콜시스템, TTSC 등 JAVA 기반 시스템들을 개발하고 있습니다.

디자인 전공부터 컴퓨터학과 편입으로 쌓아온 CS 지식을 활용해 기획부터 설계, 개발까지 구조화된 개발을 하고 있습니다.

## 기술 스택

| 분야 | 사용 기술 |
| --- | --- |
| 프론트엔드 | React, TypeScript, Zustand, styled-components |
| 백엔드 | Java, Spring Boot, JPA, MyBatis |
| 데이터 | MariaDB, Oracle, Redis |
| 인프라 | Docker, Linux, Nginx, CI/CD |

## 이 블로그

개발하면서 정리한 기술 개념과 실제로 부딪힌 문제를 기록합니다.

코드는 [GitHub](https://github.com/NabongS2)에 있습니다.
