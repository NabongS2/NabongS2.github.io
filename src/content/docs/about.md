4년차 웹 풀스택 JAVA 개발자 **나봉**입니다.

AICC 콜봇을 도메인으로 하는 기술 연구소에서 웹 어드민과 콜봇 시스템에 필요한 데이터 설계, 그리고 JAVA 기반 시스템들을 개발하고 있습니다.

디자인 전공으로 시작해 컴퓨터과학과로 편입했습니다. 거기서 쌓은 CS 지식을 바탕으로 기획부터 설계, 개발까지 구조화된 개발을 하고 있습니다.

## 주요 프로젝트

- **콜봇 운영 관리**
- **STT 운영 관리**
- **CAS** — 콜 시스템
- **TTSC** — TTS 엔진
- **시나리오 빌더 + NLU 사전 등록 시스템**
- **설문조사 콜봇 어드민**
- **어드민 시스템 모노레포 구축**

## 기술 스택

견고한 아키텍처를 설계하고 운영 효율을 높이기 위해 실무에서 적극적으로 활용하는 기술들입니다.

| 분야 | 주력 | 그 외 |
| --- | --- | --- |
| 프론트엔드 | React, TypeScript, React Flow, Zustand | JavaScript (ES6+), HTML5 / CSS3, styled-components, Ant Design |
| 백엔드 | Java, Spring Boot, REST API 아키텍처 | Spring Framework, JPA / Hibernate, MyBatis |
| 데이터 · 미들웨어 | RDB, Redis, RabbitMQ, WebSocket / SSE | MariaDB, Oracle, Webhook 연동 |
| DevOps | pnpm (모노레포), Vite, Docker, Linux | Nginx, GitLab CI/CD |
| 디자인 | Figma | Photoshop, Illustrator |
| 협업 | Git / GitLab | Storybook, Jira / Redmine, SVN |
