**나봉**입니다. 웹 서비스를 만듭니다. 화면부터 백엔드, 배포까지 한 줄기를 통째로 다루는 편입니다.

주로 파고드는 건 **반복 업무의 병목**입니다. 손으로 하던 일을 인터페이스로 옮기고, 흩어진 코드를 공통 모듈로 묶는 쪽에 시간을 씁니다.

## 관심 있는 것

- 복잡한 데이터 구조를 눈으로 볼 수 있게 만드는 일 — 그래프, 에디터, 대시보드
- 모노레포와 공통 패키지 설계
- 빌드·배포 자동화

## 기술 스택

| 분야 | 사용 기술 |
| --- | --- |
| 프론트엔드 | React, TypeScript, Zustand, styled-components |
| 백엔드 | Java, Spring Boot, JPA, MyBatis |
| 데이터 | MariaDB, Oracle, Redis |
| 인프라 | Docker, Linux, Nginx, CI/CD |
